# Issue #2046 CI pause and restoration

The owner paused hosted CI on 2026-11-01 while completing #2046. The source
baseline for this temporary removal is `9242346ee2e070873ed9a1015115ecbc2bc0553b`.
This branch removes the 34 tracked GitHub workflow files from `main`. The
repository Actions setting and 40 registered YAML workflows were also disabled;
the active `main` ruleset's automatic Copilot review rule was removed while its
other protections remain active. The exact API state and workflow IDs are in
[#2046's CI pause comment](https://github.com/waddle-social/waddle/issues/2046#issuecomment-6561052066).

## Restoration after implementation

Keep Actions disabled until the code and local review are complete. Then:

1. Run `cuenv sync -A` and inspect the generated diff. This restores the 27
   workflows whose files say `Generated by cuenv` and synchronizes the rest of
   the workspace's cuenv outputs.
2. Regenerate the three workflows owned by other source files:
   `bash scripts/sync-cache-benchmark.sh`,
   `bun scripts/integration-ci.ts sync`, and
   `bash scripts/sync-rust-tests.sh`. Inspect their diffs.
3. Restore the four manually maintained workflows from the baseline commit,
   then review them against any deliberate source changes since the pause:
   `hestia-cache-gc.yml`, `operational-qualification.yml`,
   `waddle-apple-default.yml`, and `waddle-apple-pullrequest.yml`.
4. Verify that all intended workflow files are back, commit and push the
   restoration, then restore the GitHub Actions setting, baseline YAML workflow
   enablement and the automatic Copilot review rule using the saved API state.
   Run required hosted CI and resolve failures before closing #2046.

The pause is reversible through Git history. Do not infer that `cuenv sync -A`
alone restores the seven files in steps 2 and 3.
