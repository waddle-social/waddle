# Actor and remote-resource mirror edge ledger

Source target: `4219bdd71af9fb0116c82a5c33ab1ed98eecc35d`.
The original bounded review used `718f47a9e08f29cf2e6157803770e2f495fe201e`,
whose server tree matched `5763923e`. The affected owner-update ordering paths
were re-inspected and their links refreshed for the current target. This is a **bounded, manually traced**
ledger of the paths below, not an exhaustive inventory of all actor callers,
all compiler sites, all cfg combinations, or a proof of the #2046 ownership
and custody contract. The existing [grouped inventory](account-route-semantic-inventory.md)
is a starting point, not an additional coverage claim.

`Authority` means the current decision made at the cited edge, not proof of a
single distributed owner. `Derived index` denotes a secondary copy maintained
for lookup, demotion or convergence; `transport` denotes a transfer or relay,
not necessarily a completed socket write; `obsolete` identifies a retired
surface rather than a supported query merely described by an old comment.
A `production` row means the cited path is compiled for the named feature
configuration; runtime selection and success still depend on its guards.
Cluster rows require [`clustering`](../../../server/crates/waddle-server/src/clustering/mod.rs#L71).
`test-support` in the server enables [`waddle-xmpp/test-utils`](../../../server/crates/waddle-server/Cargo.toml#L176).
