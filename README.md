# Waddle Service

Hi, we're Waddle 🐧

## Apple app (iOS + macOS)

A shared **native SwiftUI** app is available at `apps/apple` with iOS and macOS targets.

1. Install XcodeGen once: `brew install xcodegen`
2. Generate the project: `cd apps/apple && xcodegen generate`
3. Open `apps/apple/Waddle.xcodeproj` in Xcode and run either:
   - `Waddle-iOS` (iPhone/iPad)
   - `Waddle-macOS` (macOS)
