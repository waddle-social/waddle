The 64 × 64 RGB fixture is a resized version of NASA's public-domain photograph of astronaut Eileen Collins, distributed by [scikit-image](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut). The 32 × 32 confidence reference samples the center of each 8 × 8 cell of the original 256 × 256 Google MediaPipe selfie segmenter output after nearest-neighbor enlargement of the fixture.
