# Postgres-backed tests that may run outside nextest's `postgres` test group.
#
# Every test listed here connects to WADDLE_TEST_POSTGRES_URL only to create
# its own uniquely named (UUID-suffixed) schema, runs against that schema via
# search_path, and never resets or alters the shared `public` schema, so it
# cannot observe or disturb the table-resetting tests serialized in the group.
# scripts/check_postgres_test_group.py requires every other Postgres-backed
# test to match the group filter in .config/nextest.toml, and fails on entries
# here that no longer need listing.
#
# Format: one entry per line, relative to server/. `#` starts a comment.
# - `<file>`: every Postgres-backed test declared in that file is isolated.
# - `<file>::<Type or module>::<fn>`: a fixture that always creates and uses
#   its own uniquely named schema; tests whose only route to the database is
#   that fixture need no entry of their own, wherever they are declared
#   (including through `include!`).

# Fixtures.

# but `CREATE SCHEMA` / `DROP SCHEMA` of that name (`close`), and opens the
# Database, MAM, inbox and activity stores with `search_path=<schema>`. Shared
# by the integration binaries (`mod ingress_support;`) and the library
# (`include!` in src/ingress/test_support.rs).
