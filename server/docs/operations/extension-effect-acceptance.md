# Extension effect acceptance (#1660)

This matrix extends the completed direct-message executor contract. Canonical
effect receipts remain the sole completion authority; scheduling ancestry and
PubSub projection watermarks do not attest provider delivery.

| Requirement | Implementation and regression seam | Boundary |
| --- | --- | --- |
| Opaque, target-scoped keys | [Foundation bindings](../../crates/waddle-server/src/ingress_uow/effect_descendants.rs), [key derivation](../../crates/waddle-xmpp/src/ingress/keys.rs), substrate tests | Binding validates the recorded effect and target. |
| Calls/pins durable-owner boundary | [authority boundary tests](../../crates/waddle-server/src/ingress_uow/reconciliation_authority_tests.rs) | `CallSignal`, `Pin`, `DmPinMutation` and `DmCallThreadState` return `AwaitingDurableOwner` and cannot attach scheduling descendants, including after an operational mutation receipt. A supported effect remains bindable. |
| Atomic activity/preview acceptance | [projection executor](../../crates/waddle-server/src/ingress/execute_projection.rs), [projection tests](../../crates/waddle-server/src/ingress/execute_projection_tests.rs) | SQLite/PostgreSQL mutation, key binding and receipt roll back together. Completed replay preserves newer activity, including a newer gone state. |
| Approved preview restitution | [preview restoration](../../crates/waddle-server/src/ingress/recorded/preview_restore.rs), recorded preview/recovery tests | A retry cannot introduce freshly enriched slots; original pending slots and payloads recover from stored authority. Archive revisions fence older pointer updates. |
| Host-owned extension capability | [WIT ABI 3](../../wit/waddle-extension.wit), [runtime tests](../../crates/waddle-extensions/src/runtime/tests.rs), [server capability](../../crates/waddle-server/src/room_observation/capability.rs) | Guests receive borrowed resources, not exported keys. Runtime and server revalidate source, generation and unexpired lease. Forged/retained handles fail. |
| Durable observer output | [observer work](../../crates/waddle-server/src/ingress_uow/room_observation/work.rs), observer invocation/publication/retention suites | Approved results and publication descendants commit together. Persistence retries reuse the approved result without invoking the provider again. Unknown started work remains retryable past the former attempt cap. |
| Scoped notification custody | [candidate lineage](../../crates/waddle-server/src/notification_outbox/enqueue.rs), [ancestry tests](../../crates/waddle-server/src/notification_outbox/ancestry_tests.rs) | Fanout/coalescing preserves every parent. Explicit cancellation releases custody. Wire item IDs, even identical copies, confer no canonical authority. |
| Periodic pending notification recovery | [recovery authority](../../crates/waddle-server/src/ingress_uow/recovery_receipts.rs), [periodic recovery tests](../../crates/waddle-server/src/server/routes/interpret/offline_delivery_recovery_tests.rs), [ambiguous handoff tests](../../crates/waddle-server/src/ingress/execute_ambiguous_notification_tests.rs) | Every canonical parent is independently validated against frozen pending or deterministic route-handoff/archive provenance. Candidate custody and the pending completion marker commit together without inventing an intent or receipt. Archived ambiguous handoff pins its original route authority before notification recovery. Marked-row coalescing transfers validated notification custody before consumption can release the pending pin. Only an explicitly noncanonical memory adapter uses raw insertion. |
| Same-key durable provider queue | [queue acceptance](../../crates/waddle-server/src/push_service/publish_jobs.rs), [XEP-0357 acceptance/refusal tests](../../crates/waddle-server/tests/xep0357_outbox_acceptance.rs), [claim/schema tests](../../crates/waddle-server/src/notification_outbox/acceptance_fence_tests.rs), [malformed parking tests](../../crates/waddle-server/src/notification_outbox/malformed_outbox_tests.rs), [sticky uncertainty tests](../../crates/waddle-server/src/push_service/worker_uncertainty_tests.rs), [quota headroom tests](../../crates/waddle-server/src/push_service/publish_jobs_quota_tests.rs), queue/device/provider suites | Frozen approval alone is not queue acceptance. A durable claim-fenced marker retains possible acceptance; only a proven current-attempt refusal with no prior uncertainty can restore bounded retries or unread-zero suppression. Canonical acceptance freezes payload/options and retries the same job. Known queued pre-send failures stop at the existing attempt cap. The spec's `UnknownAfterSend` is stored as `uncertain_send`; prior uncertainty and started leases remain protected across later deterministic failures without confirmed delivery for the exact job. Fresh job-scoped delivered-sibling evidence preserves logical success; foreign jobs sharing the wire item ID supply no proof. Malformed uncertain rows leave due batches without settling custody or becoming prune-eligible. Wire publications create separate jobs and retain their original item IDs. Quota headroom is drawn from safely deletable aged terminal rows, retaining live and canonical custody. Per-device evidence is job-scoped. Keyless providers remain at-least-once. |
| Ordered PubSub backing | [versioned backing](../../crates/waddle-server/src/pubsub/versioned.rs), [SQL tests](../../crates/waddle-server/src/pubsub/versioned_tests.rs), memory storage test | Atomic revision/token/fingerprint and item writes fence delayed old retries across distinct databases. Superseded backing is not provider acceptance. Watermarks survive deletion without retaining notification text. Existing PubSub v8 data is preserved. |
| XEP-0357/0060 publication boundaries | [notification publication tests](../../crates/waddle-server/tests/notification_outbox/publish.rs), [dedicated XEP-0357 provider suite](../../crates/waddle-server/tests/xep0357_push_service_web_push.rs), [dedicated XEP-0060 republication suite](../../crates/waddle-server/tests/xep0060_push_service_publication.rs) | Stable item ID proves neither canonical authority nor provider delivery. Ordinary wire republication replaces PubSub backing while remaining a fresh queue publication. Known no-send failures respect the retry cap; prior uncertainty without same-job delivery proof remains retryable. |
| Descendant/reference retention | [retention frontier](../../crates/waddle-server/src/ingress_substrate/retention.rs), [relay ACK boundary tests](../../crates/waddle-server/src/clustering/route_bridge/tests/retention_boundary.rs), [monitoring SQL regression](../../crates/waddle-server/src/db/migrations/tests.rs), substrate/dispatch/observer tests | Aliases, keys and receipts survive until all descendants and SM/pending custody settle, then the full eight-day tail. Relay ACK does not settle ancestry. Both monitoring cohorts recognize unsettled descendant-only custody. New references invalidate eligibility under canonical locks. |
| Candidate/job prune interleavings | [locked pruning](../../crates/waddle-server/src/notification_outbox/prune.rs), [native race/frontier tests](../../crates/waddle-server/src/notification_outbox/prune/tests.rs) | Bounded canonical-first locking, child exclusion and fresh READ COMMITTED guards protect late attachments. All descendant and lineage evidence must retire before pruning; the existing batch bound remains intact. Parked uncertain failures stay retained even without local queue evidence. |
| Upgrade and concurrency | V1025, [legacy adoption](../../crates/waddle-server/src/notification_outbox/legacy_ancestry.rs), [archive-alias tests](../../crates/waddle-server/src/notification_outbox/legacy_ancestry_tests.rs), upgrade/NOWAIT suites | Additional parent locks are nonblocking and whole-transaction retries retain sanitized classes. Canonically matchable sender/identity/audit errors are quarantined with pending Foundation custody before CHECK rebuilds; dispatch/pruning/replay cannot consume them. Structural schema or canonical-authority corruption still fails closed. Legally collected startup snapshots are skipped without recreating authority. Legacy adoption uses cross-archive candidate identity and frozen sender-conversation validation, preserves frozen data and refuses to invent provider completion. Unreconstructable history remains conservatively retained. |
| Identity-free transitions | Projection, observer, notification and provider transition code | No new key, JID, plugin identity or content fields are emitted by these transitions. Projection fingerprints remain storage metadata. |

Verification and independent review are recorded on [PR #1939](https://github.com/waddle-social/waddle/pull/1939)
against its final commit. A source link or passing focused test does not assert
deployment activation. The rollout uses the [#1660 cutover](../../../docs/operations/relay-cutovers.md#extension-effect-authority-cutover-1660):
stop old collectors, apply V1025 and rebuild ABI 3 guests before restoring rolling
updates through the existing guard.
